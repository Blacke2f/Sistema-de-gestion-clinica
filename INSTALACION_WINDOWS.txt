1. REQUISITOS DEL SISTEMA
=====================================================================

  Software requerido:
  - Windows 10 / 11 (64 bits)
  - PHP 8.2 o superior (8.3 recomendado)
  - MySQL 5.7+ / 8.0+ o MariaDB 10.4+ / 10.6+
  - Apache 2.4+
  - Composer 2.x
  - mod_rewrite habilitado en Apache

  Extensiones PHP requeridas:
  - php_gd          (generacion de PDF)
  - php_mbstring    (cadenas multibyte)
  - php_fileinfo    (deteccion de tipos MIME)
  - php_openssl     (cifrado de sesiones)
  - php_pdo_mysql   (conexion a MySQL/MariaDB)
  - php_zip         (manejo de archivos ZIP)
  - php_bcmath      (calculos de precision)
  - php_intl        (internacionalizacion)

  Hardware minimo recomendado:
  - 4 GB RAM (minimo 2 GB)
  - 1 GB espacio en disco libre
  - Procesador de 64 bits
  - Conexion de red para acceso LAN

2. OPCION A: INSTALAR CON LARAGON (RECOMENDADO)
=====================================================================

  Laragon es la opcion mas sencilla para Windows. Incluye
  Apache, PHP, MySQL y Composer en un solo paquete portable.
  No requiere configuracion adicional de mod_rewrite.

  PASO 1 - Descargar e instalar Laragon
  ----------------------------------------
  1. Ve a: https://laragon.org/download/
  2. Descarga "Laragon Full 6.0+" (incluye PHP 8.x, MySQL 8, Apache)
  3. Ejecuta el instalador como Administrador
  4. Instala en C:\laragon (ruta por defecto recomendada)
  5. Abre Laragon y verifica:
     - Apache: VERDE
     - MySQL:  VERDE

  PASO 2 - Copiar el proyecto
  ----------------------------------------
  1. Copia la carpeta SISGECLIN a:
     C:\laragon\www\SISGECLIN

     La estructura debe quedar:
     C:\laragon\www\SISGECLIN\
     C:\laragon\www\SISGECLIN\public\
     C:\laragon\www\SISGECLIN\app\
     C:\laragon\www\SISGECLIN\.env

  PASO 3 - Instalar dependencias PHP (Composer)
  ----------------------------------------
  1. Abre la terminal de Laragon:
     Clic en el boton "Terminal" en la ventana de Laragon
     (o clic derecho en la bandeja del sistema > Terminal)
  2. Navega al proyecto:
     cd C:\laragon\www\SISGECLIN
  3. Instala dependencias:
     composer install --no-dev --optimize-autoloader

     Si composer no responde:
     - Ve a: https://getcomposer.org/download/
     - Descarga Composer-Setup.exe e instala
     - Reinicia la terminal de Laragon

  PASO 4 - Verificar extensiones PHP
  ----------------------------------------
  1. En Laragon: clic derecho > PHP > php.ini
     (o Menu > PHP > php.ini)
  2. Busca y descomenta estas lineas (quita el ; del inicio):
     extension=gd
     extension=mbstring
     extension=fileinfo
     extension=openssl
     extension=zip
     extension=bcmath
     extension=intl
  3. Guarda php.ini
  4. En Laragon: clic en "Reload" (reiniciar Apache)

  PASO 5 - Configurar la base de datos
  ----------------------------------------
  Ver seccion 6 de esta guia.

  PASO 6 - Acceder al sistema
  ----------------------------------------
  Abre el navegador y ve a:
  http://localhost/SISGECLIN/public

  Credenciales por defecto:
  - admin       / admin123    (Administrador)
  - medico      / admin123    (Medico)
  - recepcion   / admin123    (Recepcionista)
  - enfermera   / Admin123    (Enfermera)
  - farmacia    / Admin123    (Farmaceutico)
  - contador    / Admin123    (Contador)
  - laboratorio / Admin123    (Laboratorista)

  IMPORTANTE: Cambia las contrasenas en el primer acceso
  desde: Mi Perfil > Cambiar Contrasena

3. OPCION B: INSTALAR CON XAMPP
=====================================================================

  PASO 1 - Instalar XAMPP
  ----------------------------------------
  1. Descarga XAMPP desde: https://www.apachefriends.org/
     Versiones compatibles: XAMPP 8.2.x o 8.3.x (NO usar 7.x)
  2. Instala en C:\xampp (NO instalar en C:\Program Files)
  3. Abre XAMPP Control Panel como Administrador
  4. Inicia Apache y MySQL (deben quedar en VERDE)

  PASO 2 - Habilitar mod_rewrite en Apache
  ----------------------------------------
  1. En XAMPP Control Panel: clic en "Config" junto a Apache
  2. Selecciona "Apache (httpd.conf)"
  3. Busca la linea:   #LoadModule rewrite_module
  4. Quita el # al inicio para habilitarla
  5. Busca el bloque:  <Directory "C:/xampp/htdocs">
  6. Dentro del bloque, cambia:
       AllowOverride None
     por:
       AllowOverride All
  7. Guarda y cierra el archivo
  8. Reinicia Apache en XAMPP Control Panel

  PASO 3 - Habilitar extensiones PHP
  ----------------------------------------
  1. En XAMPP: clic en "Config" junto a Apache > PHP (php.ini)
  2. Busca y descomenta (quita el ; del inicio):
     extension=gd
     extension=mbstring
     extension=fileinfo
     extension=zip
     extension=intl
  3. Guarda y reinicia Apache

  PASO 4 - Copiar el proyecto
  ----------------------------------------
  1. Copia la carpeta SISGECLIN a:
     C:\xampp\htdocs\SISGECLIN
  2. Abre CMD como Administrador en esa carpeta
  3. Ejecuta: composer install --no-dev --optimize-autoloader

  PASO 5 - Configurar .env para XAMPP
  ----------------------------------------
  Edita C:\xampp\htdocs\SISGECLIN\.env y verifica:
  APP_URL=http://localhost/SISGECLIN/public
  DB_PASSWORD=       <- dejar vacio (XAMPP no tiene clave por defecto)

  PASO 6 - Acceder
  ----------------------------------------
  http://localhost/SISGECLIN/public

4. OPCION C: INSTALAR CON WAMP
=====================================================================

  PASO 1 - Instalar WampServer
  ----------------------------------------
  1. Descarga desde: https://www.wampserver.com/
  2. Instala WampServer 3.3.x o superior (64 bits)
     Requiere redistribuibles VC++ (el instalador los descarga)
  3. Abre WampServer (icono verde en la barra de tareas)
     Si el icono es NARANJA o ROJO, hay un problema de puerto.

  PASO 2 - Cambiar puerto si hay conflicto
  ----------------------------------------
  Si Apache no inicia (puerto 80 ocupado por Skype o IIS):
  1. Clic en icono WampServer > Apache > httpd.conf
  2. Cambia: Listen 80  por  Listen 8080
  3. Reinicia Apache
  4. Accede por: http://localhost:8080/SISGECLIN/public

  PASO 3 - Habilitar mod_rewrite
  ----------------------------------------
  1. Clic en icono WampServer > Apache > Apache Modules
  2. Busca y marca: rewrite_module
  3. Apache se reinicia automaticamente

  PASO 4 - Configurar VirtualHost (recomendado)
  ----------------------------------------
  1. Clic en WampServer > Apache > httpd-vhosts.conf
  2. Agrega al final del archivo:

     <VirtualHost *:80>
         DocumentRoot "c:/wamp64/www/SISGECLIN/public"
         ServerName sisgeclin.local
         <Directory "c:/wamp64/www/SISGECLIN/public">
             AllowOverride All
             Require all granted
         </Directory>
         ErrorLog "c:/wamp64/logs/sisgeclin_error.log"
     </VirtualHost>

  3. Edita C:\Windows\System32\drivers\etc\hosts (como admin):
     127.0.0.1    sisgeclin.local
  4. Reinicia Apache

  PASO 5 - Copiar e instalar
  ----------------------------------------
  1. Copia SISGECLIN a: C:\wamp64\www\SISGECLIN
  2. Abre CMD: cd C:\wamp64\www\SISGECLIN
  3. Ejecuta: composer install --no-dev --optimize-autoloader

  PASO 6 - Acceder
  ----------------------------------------
  Con VirtualHost:  http://sisgeclin.local
  Sin VirtualHost:  http://localhost/SISGECLIN/public

5. OPCION D: INSTALACION MANUAL (AVANZADO)
=====================================================================

  Si prefieres instalar PHP y Apache individualmente sin un paquete
  AMP (para servidores Windows dedicados):

  PASO 1 - Instalar PHP
  ----------------------------------------
  1. Descarga PHP 8.3 desde: https://windows.php.net/download/
     Selecciona: PHP 8.3.x Non Thread Safe (x64) ZIP
  2. Extrae en: C:\php
  3. Agrega C:\php al PATH del sistema:
     Panel de Control > Sistema > Variables de entorno > PATH
  4. Copia C:\php\php.ini-production a C:\php\php.ini
  5. Edita php.ini y habilita las extensiones necesarias
  6. Verifica: php -v  (debe mostrar la version)

  PASO 2 - Instalar Apache
  ----------------------------------------
  1. Descarga Apache desde: https://www.apachelounge.com/download/
     Selecciona: httpd-2.4.x-winXX-VS17.zip (VS17 = Visual C++ 2022)
  2. Extrae en C:\Apache24
  3. Edita C:\Apache24\conf\httpd.conf:
     - ServerRoot "c:/Apache24"
     - Define SRVROOT "c:/Apache24"
     - DocumentRoot "c:/Apache24/htdocs"
     - Descomenta: LoadModule rewrite_module modules/mod_rewrite.so
     - Cambia AllowOverride None por AllowOverride All
  4. Instala como servicio:
     cd C:\Apache24\bin
     httpd.exe -k install
     httpd.exe -k start
  5. Verifica en: http://localhost

  PASO 3 - Instalar Composer
  ----------------------------------------
  1. Descarga desde: https://getcomposer.org/download/
  2. Instala Composer-Setup.exe
  3. Verifica: composer --version

  PASO 4 - Configurar Apache para PHP
  ----------------------------------------
  Agrega al final de C:\Apache24\conf\httpd.conf:

  PHPIniDir "C:/php"
  LoadModule php_module "C:/php/php8apache2_4.dll"
  AddType application/x-httpd-php .php

  Reinicia Apache: httpd.exe -k restart

  PASO 5 - Configurar VirtualHost
  ----------------------------------------
  Agrega en C:\Apache24\conf\extra\httpd-vhosts.conf:

  <VirtualHost *:80>
      DocumentRoot "C:/inetpub/wwwroot/SISGECLIN/public"
      ServerName sisgeclin.local
      <Directory "C:/inetpub/wwwroot/SISGECLIN/public">
          AllowOverride All
          Require all granted
      </Directory>
  </VirtualHost>

6. CONFIGURAR LA BASE DE DATOS (TODOS LOS ENTORNOS)
=====================================================================

  METODO A: Importar SQL con datos de prueba (mas rapido)
  ----------------------------------------
  1. Abre phpMyAdmin:
     Laragon: http://localhost/phpmyadmin
     XAMPP:   http://localhost/phpmyadmin
     WAMP:    http://localhost/phpmyadmin
  2. Crea una nueva base de datos:
     - Nombre:      sisgeclin_laravel
     - Cotejamiento: utf8mb4_unicode_ci
  3. Selecciona la base de datos creada en el panel izquierdo
  4. Clic en la pestana "Importar"
  5. Clic en "Elegir archivo"
  6. Selecciona: SISGECLIN\database\sisgeclin_laravel.sql
  7. Clic en "Continuar" (puede tardar 10-30 segundos)

  METODO B: Migraciones (instalacion limpia sin datos)
  ----------------------------------------
  En CMD dentro de la carpeta del proyecto:

  php artisan migrate --force
  php artisan db:seed --class=DatosPruebaSeeder

  METODO C: Linea de comandos MySQL
  ----------------------------------------
  Si prefieres usar la linea de comandos:

  # Laragon
  C:\laragon\bin\mysql\mysql8.4.3\bin\mysql.exe -u root -p

  # XAMPP
  C:\xampp\mysql\bin\mysql.exe -u root -p

  # En el prompt de MySQL:
  CREATE DATABASE sisgeclin_laravel
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;
  USE sisgeclin_laravel;
  SOURCE C:/laragon/www/SISGECLIN/database/sisgeclin_laravel.sql;
  EXIT;

7. CONFIGURAR EL SISTEMA (.env)
=====================================================================

  El archivo .env ya viene configurado para Laragon.
  Para otros entornos, edita .env con un editor de texto (Notepad++):

  Configuracion basica:
  ----------------------------------------
  APP_NAME="SISGECLIN"
  APP_ENV=production
  APP_DEBUG=false
  APP_URL=http://localhost/SISGECLIN/public

  Configuracion de base de datos:
  ----------------------------------------
  DB_CONNECTION=mysql
  DB_HOST=127.0.0.1
  DB_PORT=3306
  DB_DATABASE=sisgeclin_laravel
  DB_USERNAME=root
  DB_PASSWORD=         <- vacio para Laragon/XAMPP sin clave

  Configuracion de sesion:
  ----------------------------------------
  SESSION_DRIVER=file
  SESSION_LIFETIME=480
  SESSION_DOMAIN=       <- dejar vacio para acceso multi-IP

  Despues de editar .env, ejecuta en CMD:
  ----------------------------------------
  cd C:\laragon\www\SISGECLIN
  php artisan sisgeclin:clear

  Crear enlace de almacenamiento (obligatorio):
  ----------------------------------------
  php artisan storage:link

  Verificar que funciona:
  ----------------------------------------
  php artisan about

8. ACCESO EN RED LOCAL (WiFi/LAN)
=====================================================================

  Para que otros dispositivos (telefono, tablet, otra PC)
  accedan al sistema desde la misma red WiFi:

  METODO RAPIDO - Script automatico
  ----------------------------------------
  1. Haz doble clic en ABRIR_FIREWALL.bat
  2. Selecciona "Ejecutar como administrador"
  3. El script:
     - Detecta Apache automaticamente (Laragon/XAMPP/WAMP)
     - Abre el puerto 80 en el firewall de Windows
     - Muestra tu IP local para compartir

  METODO MANUAL - Abrir firewall
  ----------------------------------------
  1. Abre "Firewall de Windows Defender con seguridad avanzada"
     (busca en el menu inicio)
  2. Reglas de entrada > Nueva regla
  3. Tipo: Puerto
  4. Puerto TCP especifico: 80
  5. Permitir la conexion
  6. Nombre: Apache HTTP
  7. Aplicar

  Obtener tu IP local:
  ----------------------------------------
  Abre CMD y escribe:
  ipconfig
  Busca: "Adaptador de Ethernet" o "Adaptador de LAN inalambrica"
  Copia: Direccion IPv4 (ej: 192.168.1.5)

  Acceso desde otros dispositivos:
  ----------------------------------------
  En el navegador del otro dispositivo:
  http://192.168.1.5/SISGECLIN/public

  Requisitos:
  - Ambos dispositivos en la misma red WiFi o LAN
  - Apache activo y en verde
  - El firewall permite el puerto 80

9. BACKUP AUTOMATICO
=====================================================================

  El sistema hace backup automatico de la BD a las 2:00 AM.
  Para configurarlo en Windows:

  USANDO PROGRAMADOR DE TAREAS DE WINDOWS
  ----------------------------------------
  1. Abre "Programador de tareas" (busca en inicio)
  2. Accion > Crear tarea basica
  3. Nombre: SISGECLIN - Backup Diario
  4. Detonador: Diariamente a las 02:00 AM
  5. Accion: Iniciar un programa
     Programa/script:
       C:\laragon\bin\php\php-8.3.30-Win32-vs16-x64\php.exe
     Argumentos:
       C:\laragon\www\SISGECLIN\artisan db:backup --keep=7
  6. Marcar: Ejecutar tanto si el usuario inicio sesion como si no

  BACKUP MANUAL
  ----------------------------------------
  Abre CMD en la carpeta del proyecto y ejecuta:
  php artisan db:backup
  php artisan db:backup --keep=14    (conservar 14 dias)

  Los backups se guardan en:
  storage\app\backups\backup_sisgeclin_laravel_AAAA-MM-DD.sql

10. SOLUCION DE PROBLEMAS COMUNES
=====================================================================

  Error: Pantalla en blanco o "Whoops"
  ----------------------------------------
  1. Activa el modo debug temporalmente en .env:
     APP_DEBUG=true
  2. Recarga la pagina para ver el error real
  3. Revisa: storage\logs\laravel.log
  4. Ejecuta: php artisan sisgeclin:clear
  5. Ejecuta: composer dump-autoload
  6. Verifica que vendor/ exista

  Error: "Class not found"
  ----------------------------------------
  1. php artisan sisgeclin:clear
  2. composer dump-autoload --optimize
  3. Verifica que vendor/ exista (ejecuta composer install)

  Error: "SQLSTATE Connection refused" o "Access denied"
  ----------------------------------------
  1. Verifica que MySQL/MariaDB este activo (VERDE en Laragon)
  2. Revisa las credenciales en .env
  3. Prueba con DB_HOST=localhost en lugar de 127.0.0.1
  4. En phpMyAdmin verifica que la BD exista con el nombre exacto

  Error 403 Forbidden
  ----------------------------------------
  1. Verifica que mod_rewrite este habilitado
  2. En httpd.conf: AllowOverride All (no None)
  3. Verifica que exista public\.htaccess
  4. Reinicia Apache

  Error 404 en rutas del sistema
  ----------------------------------------
  1. Verifica la URL: debe terminar en /SISGECLIN/public/...
  2. Ejecuta: php artisan route:clear
  3. Verifica public\.htaccess existe y tiene contenido

  Error al generar PDF de recetas
  ----------------------------------------
  1. Verifica que extension=gd este activa en php.ini
  2. Crea manualmente: storage\app\mpdf\  (si no existe)
  3. Da permisos:
     icacls "C:\laragon\www\SISGECLIN\storage" /grant Users:F /T

  Las fotos de recetas manuscritas no cargan
  ----------------------------------------
  1. Ejecuta: php artisan storage:link
  2. Verifica que existe el enlace simbolico:
     public\storage -> storage\app\public
  3. Verifica permisos de escritura en storage\app\public\

  Puerto 80 ocupado (Apache no inicia)
  ----------------------------------------
  El puerto 80 puede estar usado por:
  - Skype (cambia en opciones > avanzado > deshabilitar 80/443)
  - IIS (detener desde Administrador de IIS o servicios.msc)
  - SQL Server Reporting Services
  Para verificar: netstat -ano | findstr :80

  La aplicacion va lenta en la primera carga
  ----------------------------------------
  1. Ejecuta: php artisan optimize
  2. Esto precarga las rutas y configuracion en cache

  OPcache no recarga cambios de PHP
  ----------------------------------------
  Al modificar archivos PHP, reinicia Apache en Laragon
  para que OPcache recargue los cambios:
  Clic derecho en Laragon > Reload o Restart All Services
